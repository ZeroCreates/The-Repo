RIFT LAUNCHER

A full desktop-style launcher for ComputerCraft (CC:Tweaked): apps, accounts, notifications, background services and self-updating, all from one computer.

Install

On a computer, download the launcher and boot it:

wget https://rift.zerocreates.org/launcher.lua launcher.lua
launcher

On every boot the launcher checks the website for a new version, shows a boot screen while it updates, then reboots into the new build. If an update fails to start, it rolls back automatically.

Features

Self-updating

Updates from rift.zerocreates.org/launcher.lua with safe rollback and a black-box log.

App Downloader

Install and update apps from the online catalog.

Multitasking

Run several apps at once. Press Ctrl+T for the session menu; the launcher itself can never be terminated.

Rift Account

One sign-in and create-account page handled by the launcher for every app.

Notifications

Apps and services can raise notifications with a chime; Email and Market use this.

Background services

Headless services that can persist across reboots, with permission prompts.

Permissions

Peripherals are blocked until you allow them (modems excepted). Decisions are stored per user.

Lock screen & themes

Lock the computer and pick a theme in Settings.

Developer API

Apps run in a sandbox with a global rift table:

Apps started from the launcher get these modules. Failing calls return nil/false, message unless noted. Guard against older launchers by checking the module exists first.

if type(rift) ~= "table" or type(rift.account) ~= "table" then
  error("Update the launcher.")
end

Core

CallDescription
rift.versionAPI version string ("1").
rift.user()Name of the launcher profile that is signed in.
rift.notifications()Array of recent notification texts (last 20).
rift.settings.get(key, default)Read a launcher setting.
rift.settings.set(key, value)Write a setting. Values must be string, number or boolean. Returns true when saved.

rift.notify

rift.notify(text [, options]) shows a toast in the status bar and keeps it in history. Control characters are stripped and text is cut to 120 characters. The sending app is attached automatically and muted apps are ignored.

OptionDescription
titlePrefix shown as Title: text (30 chars max).
keyUnique id (64 chars max). Identical text for the same key is skipped; new text replaces the old entry.
priority"low" (3s, silent), "normal" (5s, chime) or "high" (10s, chime).
rift.notify("3 new messages", { title = "Email", key = "mail-unread", priority = "high" })

rift.account

One shared Rift account per launcher profile. Credentials are stored in the profile's encrypted storage, so apps never need their own sign-in screen.

CallDescription
signIn([options])Returns the current user, auto-logs in with saved credentials, or shows the launcher sign-in / create-account page. Returns the username, or nil if cancelled. options.reason adds a line to the page.
current()Username signed in this session, or nil.
saved()Saved username, or nil.
auto()Log in with saved credentials. Returns ok, usernameOrError. Use it in background services.
login(user, pass)Returns ok, usernameOrError.
register(user, pass)Create the account and sign in. Returns ok, usernameOrError.
logout()Clears the saved password and signs out on the server.
get(key, default)Read extra per-account data (such as a delivery address). username and password are reserved.
set(key, value)Store extra per-account data. Returns true when saved; needs a saved account.
local name = rift.account.signIn({ reason = "Your wallet is tied to your Rift name." })
if not name then return end
rift.account.set("favourite", "dice")

rift.service

Headless background programs that keep running while you use other apps. Starting one asks the user for permission (Y once, A always, N deny, D never). Names use letters, digits, _ . - and at most 32 characters.

CallDescription
persistInit(name, fn [, options])Put at the top of the app. Only declares the endpoint; options.displayName sets the label. After a reboot the launcher re-runs the app hidden, starts fn as the service when this call is reached, and discards the rest of the run.
spawn(name [, fn] [, options])Registers and starts the service (asks permission). If persistInit declared the same name, fn can be omitted and the service is restored on every login. Returns ok, reason.
forget(name)Stops a persistent service from returning after reboot.
install(name, path, opts)Register a program in the profile (path relative to home) as a managed service. opts: displayName, description, startType, recovery.
uninstall(name)Stop and remove an installed service.
start(name) / stop(name) / restart(name)Control an installed service. A disabled service cannot start.
setStartType(name, type)"automatic", "manual" or "disabled".
status(name)"Running", "Stopped", "Failed: reason", or nil if unknown.
list()Array of { name, displayName, description, path, startType, recovery, status }.

recovery = "restart" restarts the service if it crashes. Services run without a screen, so they must not draw or read input; use rift.notify to talk to the user. Hold Alt while the Ctrl+T menu is open to reach the Services submenu.

-- top of the app
rift.service.persistInit("mail-notify", function()
  while true do
    pcall(rift.account.auto)
    -- poll the server, then:
    rift.notify("New mail", { key = "mail" })
    sleep(30)
  end
end, { displayName = "Mail notifier" })

-- later, when the user enables notifications
local ok, reason = rift.service.spawn("mail-notify")
if not ok then print(reason) end

rift.permissions

Capabilities are remembered per user. "peripheral:<type>" is requested automatically when an app wraps or finds a peripheral; modems are always allowed. Denied access makes peripheral.wrap and peripheral.find return nil and peripheral.call raise an error, so always nil-check. Background and locked contexts cannot prompt and deny anything without a saved decision.

CallDescription
has(capability)true if already granted (always or this session). Never prompts.
request(capability [, label])Asks the user if undecided; returns true or false. label is the text shown in the prompt.
revoke(capability)Forget the decision so the user is asked again.
list()Array of { capability, allowed } for saved decisions.
local printer = peripheral.find("printer")
if not printer then
  rift.ui.notice("No printer, or access was denied.")
  return
end

rift.ui

Themed dialogs drawn over the app's screen. Each redraws the app afterwards by sending a term_resize event.

CallDescription
notice(message [, title])Message box; closes on any key or click.
confirm(message [, title])Returns true for Y/Enter, false for N/Esc.
menu(title, items)Arrow keys or mouse to pick. Returns the item index, or nil on Esc.
input(prompt [, options])Text prompt. options: title, hidden (mask with *), default. Returns the text.
theme()Current launcher theme info (including the accent colour).
local pick = rift.ui.menu("Difficulty", { "Easy", "Normal", "Hard" })
if pick and rift.ui.confirm("Start on " .. ({ "Easy", "Normal", "Hard" })[pick] .. "?") then
  local name = rift.ui.input("Player name", { title = "New game" })
end

rift.storage

Private, encrypted JSON storage for the current profile. Names may contain letters, numbers, dots, underscores, dashes and / for sub-folders (no ..). Writes are atomic with a backup.

CallDescription
read(name)Returns the stored value, or nil, error.
write(name, value)Value must be JSON-serializable. Returns true or false, error.
delete(name)Remove stored data.
list([folder])Names inside the storage root or a folder.
rift.storage.write("mygame/save", { level = 3 })
local save = rift.storage.read("mygame/save") or { level = 1 }

Good to know

  • Paths appear as H:// (home) and S:// (system).
  • Updating needs roughly 400 KB of free disk space.
  • Peripherals other than modems prompt for permission the first time an app uses them.
